Menu lengkap: link soal CBT (1-12), link portal tutor, video YouTube, kontak WhatsApp, foto kegiatan, brosur PDF, artikel, kalender, dan album.

GitHub Soal CBT Link Tutor Video Kontak Foto Brosur Artikel Kalender Album
Penting: dashboard ini memakai GitHub API. Untuk menyimpan data ke website, admin perlu memasukkan GitHub token pada Bagian 1 di bawah.

1. Pengaturan GitHub

Token hanya disimpan di memori browser ini untuk keperluan update file web.

2. Pengaturan Link Soal Ujian Online CBT (Kelas 1 s.d. 12)

Tempel link Google Form (atau kode sematan <iframe>) per tingkatan kelas. Siswa otomatis mendapatkan soal sesuai kelasnya.

3. Pengaturan Link Portal Tutor & Google Drive

Kelola link Google Spreadsheet nilai rekap ujian CBT, folder tugas masuk, dan folder Google Drive modul materi santri.

4. Pengaturan Video Profil YouTube

Ubah video YouTube yang tampil di halaman beranda website PKBM Pelita Aushaf Indonesia.

Setelah disimpan, tunggu 1-2 menit lalu refresh halaman depan website.

5. Pengaturan Kontak Website

Nomor ini akan dipakai untuk tombol WhatsApp, formulir pendaftaran, tanya brosur, agenda, dan konsultasi.

6. Upload Foto Kegiatan

Bisa memilih banyak foto sekaligus. Foto akan dikompresi otomatis agar ringan diakses.
Lihat Website

7. Kelola / Hapus Foto Kegiatan

Pilih program, lalu klik Muat Foto untuk melihat dan menghapus foto yang tidak diperlukan.

Masukkan GitHub Token, pilih program, lalu klik Muat Foto.

8. Upload Brosur PDF Per Program

Setiap program dapat memiliki brosur PDF sendiri. Brosur lama bisa dihapus dari daftar.

Masukkan GitHub Token, lalu klik Muat Daftar Brosur.

9. Artikel Parenting & Edukasi

Tambah dan kelola artikel parenting, pendidikan inklusi, dan info program.

Mode edit artikel aktif. Ubah data lalu klik Simpan Artikel.
Masukkan GitHub Token, lalu klik Kelola / Hapus Artikel.

10. Kalender Akademik & Kegiatan

Kelola agenda kegiatan agar wali murid dapat melihat informasi terbaru di website.

Mode edit kegiatan aktif. Ubah data lalu klik Simpan Kegiatan.
Masukkan GitHub Token, lalu klik Kelola / Hapus Kegiatan.

11. Galeri Album

Buat album kegiatan pilihan untuk ditampilkan di galeri utama.

Masukkan GitHub Token, lalu klik Kelola / Hapus Album.
