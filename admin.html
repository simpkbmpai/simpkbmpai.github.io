Dashboard Foto Kegiatan

PKBM Pelita Aushaf Indonesia

Penting: dashboard ini gratis dan memakai GitHub sebagai tempat penyimpanan foto. Untuk upload, admin perlu memasukkan GitHub token yang punya izin menulis ke repository. Jangan bagikan token ke orang lain dan jangan simpan token di komputer umum.

1. Pengaturan GitHub

Token hanya dipakai di browser ini untuk mengirim file ke repository GitHub. Token tidak dimasukkan ke file web.

2. Upload Foto Kegiatan

Bisa memilih banyak foto sekaligus. Foto akan dikecilkan otomatis agar ringan saat tampil di web.
Lihat Website

3. Kelola Banyak Foto / Hapus Foto Kegiatan

Pilih program, lalu klik Muat Foto. Setelah daftar foto muncul, admin bisa menghapus foto yang tidak ingin ditampilkan.

Masukkan GitHub Token, pilih program, lalu klik Muat Foto.

4. Upload Brosur PDF Per Program

Gunakan bagian ini untuk mengunggah brosur PDF khusus. Setiap program bisa memiliki brosur sendiri. Brosur yang sudah tidak dipakai bisa dihapus melalui daftar di bawah.

Masukkan GitHub Token, lalu klik Muat Daftar Brosur.

Cara Membuat GitHub Token

  1. Buka GitHub → klik foto profil → Settings.
  2. Pilih Developer settings → Personal access tokens → Fine-grained tokens.
  3. Klik Generate new token.
  4. Pilih repository simpkbmpai.github.io.
  5. Pada permission, bagian Contents pilih Read and write.
  6. Generate token, copy, lalu tempel di kolom token dashboard ini.
