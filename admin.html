GitHub Soal CBT Video Kontak Foto Brosur Artikel Kalender Album
Penting: dashboard ini memakai GitHub API. Untuk menyimpan perubahan, admin perlu memasukkan GitHub token yang punya izin menulis ke repository.

1. Pengaturan GitHub

Token hanya disimpan sementara di memori browser ini untuk update data.

2. Pengaturan Link Soal Ujian Online (CBT)

Tempel link Google Form (atau kode sematan <iframe>) per jenjang. Sistem akan otomatis merapikan URL sematannya.

Tip: Anda bisa langsung menyalin dari Google Form → Kirim → Sematkan HTML (Kode iframe), sistem akan otomatis mengambil link aslinya.

3. Pengaturan Video Profil YouTube

Ubah video YouTube yang tampil di halaman beranda website PKBM Pelita Aushaf Indonesia.

Setelah disimpan, tunggu 1-2 menit lalu refresh halaman depan website.

4. Pengaturan Kontak Website

Nomor ini akan dipakai untuk tombol WhatsApp, formulir pendaftaran, tanya brosur, agenda, dan konsultasi.

5. Upload Foto Kegiatan

Bisa memilih banyak foto sekaligus. Foto akan dikompresi otomatis agar cepat diakses.

6. Kelola / Hapus Foto Kegiatan

Pilih program, lalu klik Muat Foto untuk melihat atau menghapus foto.

Masukkan GitHub Token, pilih program, lalu klik Muat Foto.

7. Upload Brosur PDF Per Program

Masukkan GitHub Token, lalu klik Muat Daftar Brosur.

Masukkan GitHub Token, lalu klik Kelola / Hapus Artikel.
